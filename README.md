# 🧑‍💻 Portfólio

Este é o meu portfólio pessoal, onde compartilho meus projetos, habilidades e experiências como desenvolvedor. Aqui você encontrará uma coleção de trabalhos que refletem minha paixão por criar soluções inovadoras e eficientes.

## ✨ Funcionalidades
- **Projetos Destacados**: Uma seção dedicada aos meus projetos mais recentes e relevantes
- **Habilidades**: Uma lista das minhas principais habilidades técnicas e ferramentas que utilizo
- **Experiência Profissional**: Um resumo da minha trajetória profissional.
- **Contato**: Formulário de contato para facilitar a comunicação.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores tecnologias do ecossistema React:

- [Next.js 16](https://nextjs.org/) - Framework React para produção.
- [React 19](https://reactjs.org/) - Biblioteca JavaScript para construção de interfaces de usuário.
- [Tailwind CSS](https://tailwindcss.com/) - Estilização baseada em utilitários.
- [Lucide/React Icons](https://react-icons.github.io/react-icons/) - Pacote de ícones.
- [TypeScript](https://www.typescriptlang.org/) - Tipagem estática para maior segurança.

## 💻 Como Rodar o Projeto
1. Clone o repositório:
   ```bash
   git clone https://github.com/Gabb83/portfolio.git
    ```
2. Navegue até o diretório do projeto:
    ```bash
    cd portfolio
    ```
3. Instale as dependências (certifique-se de ter o Node.js instalado):
    ```bash
    npm install
    ```
4. Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
5. Abra o navegador e acesse `http://localhost:3000` para ver o aplicativo em ação.
